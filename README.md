# Rimworld-Statistics

RimWorld 1.7 向けに設計中の MOD です。全セーブ・全コロニーを通した、通算のプレイ統計を表示します。

タイトル画面から、どのセーブもロードせずに、次のような値を確認できることを目標とします。
- 通算ゲーム内日数
- エンディング到達回数（種類別）
- 最高資産の合計
- コロニー数、実プレイ時間、襲撃・死亡の累計など

MOD 導入前のセーブ（1.5〜1.7）も取り込みます。
