# Rimworld Statistics

**RimWorld 1.7向け・全セーブ横断の通算統計MOD**

過去にプレイしたコロニーの記録をまとめ、RimWorldの**タイトル画面から、セーブデータを個別にロードせずに**閲覧できます。利用可能なセーブと、MODが保存した統計プロフィールをもとに集計します。

## 主な機能

- **全コロニーの通算記録**：ゲーム内日数、実プレイ時間、コロニー数、エンディング到達回数（種類別）など。
- **歴代の実績**：資産の最高記録、襲撃、死亡、クエストなど、取得可能な履歴と累計。
- **コロニー間の比較**：コロニー別の記録、最多・最少のコロニー、代表保存時点の人数・物資などの横断集計。
- **詳細統計**：全コロニー合計とコロニー別の数値を一覧表示。グラフは使用しません。
- **過去セーブの取り込み**：MOD導入前のRimWorld 1.5～1.7のセーブも、対応する範囲で**読み取り専用**で解析します。元のセーブデータは書き換えません。

## 対応MODの統計

他のMOD固有の記録も、Rimworld Statistics**本体に統合**しています。対応するゲームプレイMODは、それぞれの統計を利用するときだけ必要です。別の統計アドオンを導入する必要はありません。

**[対応MODの全一覧 / Full supported gameplay mod list（v1.7.0・40件）](docs/supported-mods.md)**

| 対象 | 記録できる内容の例 |
| --- | --- |
| **Hospitality (Continued)** | 宿泊客・グループの来訪数、ゲストベッド数、客の加入成功数、客の購入、平穏な訪問の終了 |
| **Rimworld-Recruitment** | 募集開始数、支払った銀、予定応募人数 |
| **Dubs Bad Hygiene** | 貯水量・タンク容量、給水設備の供給能力、設備の種類別数、衛生行動の完了回数 |
| **Smart Apparel Upgrade** | 自動着替えジョブの発行回数、着替えの成功回数 |
| **Vanilla Psycasts Expanded** | サイキャスターレベルの上昇、能力Def別詠唱回数、サイキャスターの状態 |
| **Vanilla Trading Expanded** | 銀行の入出金・融資、契約の納品・購入 |
| **VEF Outposts / Vanilla Outposts Expanded** | 前哨基地の稼働数、駐在人数・種類別人数、生産物の配送 |
| **Odysseyの釣り** | 成功した釣りの回数、実際に獲得したアイテムの種類別数量 |
| **その他のコンテンツMOD** | MOD追加インシデントの発生実績 |

*MOD固有の統計は、対象MODが導入されていれば初期設定で取得します。対象MODがない場合は取得処理を行わず、以前に記録した数値だけを保持します。実験的な統計は未検証のため、対象MODのバージョンや内部APIによって取得できない場合があります。*

## 導入と使い方

ゲーム内の表示はRimWorldの言語設定に従います。対応言語は日本語、英語、ドイツ語、フランス語、スペイン語（スペイン・ラテンアメリカ）、ポルトガル語（ポルトガル・ブラジル）、ロシア語、中国語（簡体字・繁体字）、韓国語です。

**動作環境：RimWorld 1.7 / 必須MOD：[Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)**

1. [Releases](https://github.com/pengin0503/Rimworld-Statistics/releases)から配布版を入手し、RimworldStatisticsフォルダをRimWorldの`Mods`フォルダに配置します。
2. MOD一覧でHarmonyとRimworld Statisticsを有効にし、ゲームを再起動します。
3. タイトル画面の**「通算統計」**から記録を表示します。「詳細統計」では項目やコロニーを切り替えられます。
4. 初期設定ですべての利用可能な統計が表示・取得対象になります。不要な統計はRimworld StatisticsのMOD設定で個別に無効化できます。統計の設定変更はゲームを再起動せず、現在のプレイ中のコロニーにも即時反映されます。

以前の独立した統計アドオン（Hospitality、Recruitment、Dubs Bad Hygiene、Smart Apparel Upgrade用）を使っていた場合は、本体統合版へ更新後に無効化してください。ゲームプレイMOD本体を削除する必要はありません。

## 記録に関する注意

- 記録が存在しない出来事は、過去セーブから必ずしも復元できません。未取得の値は**「不明」**または部分的な記録として扱い、無条件に0にはしません。
- 同じコロニーの複数セーブを、別々のコロニーとして単純加算しないように処理します。分岐したセーブの実績を無条件に合算することもありません。
- **追加統計は有効化された時点から記録します**。導入前の出来事や、対象MODを外していた期間の出来事を自動的に補完するものではありません。統計を無効化してから再度有効化した期間は記録の欠損として扱い、以前の累計は保持します。
- 初期設定では開発モードのコロニーも集計対象です。除外したい場合はMOD設定の「開発モードを含める」をOFFにしてください。
- 実験的な取得処理の数値精度や、あらゆるMOD構成での動作が保証されているわけではありません。
