# Rimworld Statistics v2.1.0

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony

## 日本語

### 主な変更

- **プロフィールの復元とバックアップを強化**しました。復元直前に作成される退避バックアップを自動保持から保護し、復元前に現在のプロフィールとバックアップの差分（コロニー数・観測数・展開後サイズなど）を確認できるようにしました。バックアップへのメモ入力、ZIP検証での展開後2GiB上限、保持上限（最大20件・合計2GiB）、短時間のロック競合の自動再試行も追加しています（退避バックアップ、ZIP検証、読み込み時の容量チェック自体は従来から存在し、今回は不足分を補いました）。
- **導入前セーブと記録の正確性を改善**しました。セーブのバージョン判定を一か所に集約し、1.5〜1.7の挙動を変えずに将来版の判定を追加しやすくしました（1.8は未対応）。「部分記録」の理由を細分化し、読み取り中にセーブが変化した場合にだけ再読み込みを1回自動で行います。時刻／tickの異常な値はエラーとして扱い、統計やチェックポイントを作りません。
- **異常の可視化と安全な復旧**を追加しました。プロフィールのサイズと256MB上限に対する割合、外部での変更検知、停止中・失敗したプロバイダー／パッチの名前、匿名診断サマリのスクロール可能なプレビューを表示します。該当する状態ではデータ管理／取り込みタブに警告バッジを付け、最新の有効なバックアップからの復旧を画面上で案内します。診断サマリにデータディレクトリやプロフィールのパスが含まれないこともテストで確認しています。
- **取り込みの導線を見直し**しました。取り込まないセーブをファイル名パターン（完全一致・前方一致・後方一致・部分一致）で設定でき、除外したセーブは読み取らず件数として表示します。記録済みセーブの「現存／アーカイブ（ファイル消失）」内訳、追加・更新されたセーブ名のサマリ、失敗したセーブごとの再検査・無視操作、セーブフォルダーを開く／パスをコピーする操作を追加しました。1つのセーブだけを強制再検査でき、タイトル画面のメニューにも進捗（完了／合計）を表示します。
- **設定・取得状況・エンディング画面を改善**しました。設定の検索、イベント／スナップショット／MODごとの折りたたみ（折りたたみ状態はセッション内のみ）、推奨する統計単位の一括選択、取得状況タブからの記録ON/OFF、エンディングの検索・並び替え・種類フィルター・コロニーへの移動、`?` ガイド、Shiftキーで技術情報（ID・キー）を表示する二段階ツールチップ、空状態からデータ管理タブへ移動するボタンを追加しました。
- **表示状態と表示形式を保存**するようになりました。詳細統計／ランキングの選択・展開状態を次回起動時にも復元します（スクロール位置は保存されません）。出典フィルター（すべて／バニラ／DLC／MOD）、日数の表示形式（小数／年と日数）、桁区切りのON/OFF、測定値がちょうど`0`の行を隠す設定、検索のAND・`-除外`構文、定義式ポップオーバー、ランキングの`/年`・`/実時間`表示、一括展開／折りたたみも追加しています。
- **ダイアログとグラフを改善**しました。ピッカーの「最近使った項目」、コロニー表示名の行内編集と元名へのリセット、現在のコロニーの強調表示、履歴グラフのズームプリセット（7／30／90日）とY軸0起点、年表の複数カテゴリ選択、区間差分ダイアログの検索・並び替え・コピー、棒グラフの並び替え・上位N・内訳検索、確認ダイアログの共通化を行いました。
- **エクスポートとリリース前の品質チェックを拡充**しました。CSVは従来どおりUTF-8 BOM付き（Excelで開ける形式）で、エクスポート先フォルダー名の指定と「フォルダーを開く」ボタン、CSVと同じ表をMarkdown／TSVとしてコピーするボタンを追加しました。取り込みエラーには安定したエラーコード（`RWS-E1xxx`）を表示し、バージョン変更後の初回起動にのみ「2.1の新機能」ダイアログを表示します。リリース前のワンコマンド検証スクリプトと、CSVヘッダー・README/Aboutのバージョン整合を確認するCIガードも追加しています。

### 更新時の注意

- 既存のプロフィール、バックアップ、設定はそのまま読み込めます。今回の変更は後方互換な追加のみで、v2.0.0で書かれたデータを読めます。新しい設定や保存された表示状態は、更新後に変更した時点から使われます。
- セーブファイルへの取り込みは従来どおり読み取り専用です。除外パターンは次のスキャンから適用されます。
- RimWorld 1.8のセーブは未対応です（従来どおり、1.7限定のセクションをスキップします）。
- 今回のUI変更はゲームビルド・Coreテスト・翻訳キー整合性チェックで検証済みですが、**実機（Reno13 A / PC）での動作確認はまだ行っていません**。最終確認はpenさんの実機チェックをお願いします。
- 「年と日数」表示を選んだ場合、すでに「日」を含む文言が重複して表示されることがあります（表示上の既知の事項）。

[対応MOD一覧（変更なし）](https://github.com/pengin0503/Rimworld-Statistics/blob/v2.1.0/docs/supported-mods.md)

## English

### What's changed

- **Safer profile restore and backups**: the automatic backup taken just before a restore is now protected from retention, and the restore confirmation shows a diff (colony/observation counts and expanded size) before writing. Backup notes, a 2 GiB expanded-size guard on ZIP dry runs, retention limits (20 backups / 2 GiB) and automatic retries for brief file-lock contention were added. The pre-restore snapshot, ZIP verification and load-time capacity check already existed; this release fills the remaining gaps.
- **Clearer pre-install and anomaly records**: save-version checks are centralized in one gate, keeping 1.5–1.7 behavior unchanged while making future versions easier to add (1.8 is still unsupported). Partial-record reasons are more specific, a save that changes while being read is retried once automatically, and anomalous time/tick values are rejected instead of producing statistics.
- **Anomaly visibility and safe recovery**: the Data management tab shows profile size and its fraction of the 256 MB cap, external-change warnings, stopped/failed provider and patch names, failed-unit/chart-cache warnings, and a scrollable read-only diagnostic preview. A warning badge appears on the Data/Import tab in affected states and a guided "restore newest valid backup" path was added. The diagnostic summary is verified not to leak data-directory or profile paths.
- **Smarter save re-checks and import controls**: saves can be ignored through filename patterns (exact, prefix, suffix or contains); ignored saves are not read and are reported separately. The import tab shows present vs. archived (file missing) record counts, added/updated file-name summaries with tooltips, and per-failed-file actions (recheck or ignore), plus buttons to open/copy the saves folder. A single save can be force-rechecked on demand, and the title-screen menu button shows running progress as `(done/total)`.
- **Better settings, coverage and endings screens**: settings can be searched and collapsed by section (collapse state is session-only) and can apply the recommended selection in one click. The Acquisition status tab toggles recording directly; Endings gains search, sort, ending-type filter and "go to colony"; the `?` guide, two-stage tooltips (hold Shift for IDs/keys) and empty-state links to Data management were added.
- **Saved view state and display formats**: Details and Rankings restore their selection and expansion state on launch (scroll positions are not persisted). Added a source filter (All / Vanilla / DLC / MOD), decimal-days vs. years+days and number-grouping display settings, a hide-zero option, shared AND/`-exclude` search, a formula popover on metric rows, per-year / per-real-hour rate units in Rankings, and expand/collapse-all controls.
- **Improved dialogs and charts**: recently used items in pickers, inline colony display-name editing with reset to original, a current-colony marker, chart zoom presets (7/30/90 days) with a Y-axis-at-zero option, multi-select chronicle categories, interval-dialog search/sort/copy, bar-chart sort/top-N/breakdown search, and unified confirmation dialogs.
- **Excel-ready CSV exports with Markdown/TSV copy and stable error codes**: CSV files remain UTF-8 with BOM; the export panel now has an export folder-name field and an "Open folder" button, and "Copy as Markdown" / "Copy as TSV" produce the same table as the CSV. Import errors now carry stable `RWS-E1xxx` codes, the "What's new in 2.1" dialog appears only once after a version change, and a one-command verification script plus new CI guards for CSV headers and About/README version consistency were added.

### Updating

- Existing profiles, backups and settings load unchanged. All changes are backward-compatible additions, so data written by v2.0.0 remains readable; new settings and saved view state take effect once changed after the update.
- Save importing remains read-only. Ignore patterns apply from the next scan.
- RimWorld 1.8 saves are not supported (1.7-only sections are skipped as before).
- The UI changes in this release were verified by builds, Core tests and translation-key checks, but **not yet on a real device (Reno13 A / PC)**. Final confirmation is pen's real-device check.
- With years+days display selected, wording that already contains "day" can read redundantly (a known cosmetic issue).
