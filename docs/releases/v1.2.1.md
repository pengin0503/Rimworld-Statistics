# Rimworld Statistics v1.2.1

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony

## 日本語

### このバージョンについて
- タイトル画面から、セーブを個別に読み込まずに**全コロニーの通算統計**を確認できます。
- RimWorld **1.5～1.7の既存セーブ**を読み取り専用で取り込めます。
- 資産、人口、心情、襲撃、クエスト、エンディングなどの詳細統計を表示します。
- 実験的な新規記録は既定OFFで、取得できない値を0として扱いません。

## English

### About this version
- View **lifetime statistics across colonies** from the title screen without loading each save into the game.
- Read-only import of existing saves from RimWorld **1.5–1.7**.
- Detailed statistics for wealth, population, mood, raids, quests, endings, and more.
- Experimental new recording is off by default, and missing values are not treated as zeros.
