# Rimworld Statistics v1.6.0 — チェックポイント退避と最適化

RimWorld **1.7** / **Harmony** 対応。v1.5.0までの全セーブ・全コロニー横断統計と内蔵MOD統計機能を維持し、長期プレイ時のプロフィール保存量と内部処理を改善した更新版です。

## 主な変更

- **T11：圧縮済みチェックポイントの退避**（[#147](https://github.com/pengin0503/Rimworld-Statistics/pull/147)）。過去のチェックポイントにある保存済み数値を追記型の `RimworldStatistics/checkpoint-archive/` に退避し、プロフィール本体の肥大化を抑制。退避済み祖先への復帰・分岐・競合時の再取込と値のマージを実装しています。退避ファイルの欠落・破損時は取得できない値を不明として扱い、勝手に0へ置き換えません。
- **T10：コードの部分クラス分割**（[#146](https://github.com/pengin0503/Rimworld-Statistics/pull/146)）。`SaveReader` と `ProfileMutations` を責務別ファイルへ整理しました。
- v1.5.0以降の読み取り、記録処理、集計、表示の最適化・リファクタリングを収録。各機能の適用範囲はリポジトリの変更履歴を参照してください。

### サイズ計測の条件

PR #147の合成データ（150項目・1000保存）で、プロファイル本体の中央値は**70.22 MB → 1.29 MB**。これは**プロフィール本体だけ**の比較で、追加の退避ファイルを含む総ディスク使用量ではありません。ゲーム内保存時間・長時間TPS改善を実測した数値ではありません。

## 保存データ・更新時の注意

- プロファイルのスキーマ番号は**2のまま**です。`archivedMetrics` は任意のフィールドで、退避先を追加します。
- **更新前に `profile.json` と `checkpoint-archive/` を併せてバックアップ**してください。退避後に旧版へ戻す場合、旧版は退避ファイルの内容を復元できないため、旧版使用時点の完全なバックアップが必要です。
- 退避先の紛失・破損は一部の過去の数値を「不明」にする可能性があります。全コロニー横断の記録を保護するため、両方を保持してください。
- v1.5.0の本体統合済みMOD統計は引き続き利用できます。個別の統計アドオンは不要で、実験的取得は引き続き既定OFFです。

- PR #147で報告されたCoreテストは**855件、失敗0・スキップ9**。チェックポイント退避の37件は失敗0。プロファイルの作業用コピーを用いた退避・再読込後の数値行も一致と報告されています。

- 実ゲームでのT11の全シナリオ、長時間TPS、すべてのMOD構成での挙動は未検証です。

## 配布物・導入方法

- 必須：**RimWorld 1.7、Harmony**（Workshop ID `2009463077`）
- 配布物：`RimworldStatistics-v1.6.0.zip` と `RimworldStatistics-v1.6.0.sha256`。
- ZIPを展開し、`RimworldStatistics` をRimWorldの `Mods` に配置、ゲームを再起動してください。
- 配布ZIPには実セーブ、`profile.json` 本体、開発用ツール、外部ゲームプレイMODのDLLを同梱しません。
