# Rimworld Statistics v1.6.0

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony

## 日本語

### 主な変更
- **比較・ランキング・お気に入り**、コロニーグループ、取得状況の表示を追加しました。
- **CSV出力**と統計プロフィールの**バックアップ・復元**に対応しました。
- 統計画面のサイズ選択、スクロール、表示速度を改善しました。
- Vanilla Psycasts Expanded、Vanilla Outposts Expanded、Hospitality、Dubs Bad Hygiene、Vanilla Trading ExpandedなどのMOD統計を拡充しました。**この版で追加した実験的な記録機能は既定OFF**です。
- 過去の統計をアーカイブに退避し、プロフィールファイルの肥大化を抑制しました。

### 軽量化の測定結果
- **初回セーブ取り込み：489.27 ms → 266.48 ms**（実セーブ3件、同一環境・各3回の中央値、ゲーム外で測定）。
- **profile.json：70.22 MB → 1.29 MB**（150項目×1,000保存の合成データ、3回の中央値）。**退避アーカイブを除くprofile.json単体のサイズ**であり、総ディスク使用量の削減率ではありません。
- 上記の数値は**実ゲーム中のTPSやセーブ時間の改善を示すものではありません**。

### 更新時の注意
v1.6.0では履歴データの保管方式が変わります。**更新前にセーブデータとRimworldStatisticsフォルダーをバックアップ**してください。更新後はprofile.jsonとcheckpoint-archiveフォルダーを一緒に保管してください。v1.5.0以前に戻す場合は更新前のバックアップが必要です。

## English

### What's changed
- Added **comparisons, rankings, Favorites**, colony groups, and recording-status information.
- Added **CSV export** and statistics-profile **backup and restore**.
- Improved window sizing, scrolling, and display performance.
- Expanded mod-specific statistics for Vanilla Psycasts Expanded, Vanilla Outposts Expanded, Hospitality, Dubs Bad Hygiene, Vanilla Trading Expanded, and others. **Experimental recording features added in this version are off by default.**
- Moved older statistics into an archive to reduce profile-file growth.

### Measured performance
- **Initial save import: 489.27 ms → 266.48 ms** (three real save files, same environment; median of three offline runs).
- **profile.json: 70.22 MB → 1.29 MB** (synthetic data: 150 metrics across 1,000 saves; median of three runs). This measures **profile.json alone, excluding the archived files**, not total disk usage.
- These measurements **do not establish an improvement in in-game TPS or save times**.

### Updating
v1.6.0 changes how historical data is stored. **Back up your saves and RimworldStatistics folder before updating.** Keep profile.json and checkpoint-archive together. To return to v1.5.0 or earlier, restore a pre-update backup.
