# Rimworld Statistics v1.9.0

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony

## 日本語

### 主な変更
- **コロニー別履歴グラフ**を追加しました。数値の推移を折れ線で表示し、複数コロニーを重ねて比較できます。セーブのつながりを確認できない記録は、誤って線で結びません。
- 統計の種類と記録範囲に応じて、**1ゲーム内日あたりの値**を比較できるようにしました。
- セーブの取り込みに失敗した理由を分類して表示します。
- **種族別・ゼノタイプ別統計**を追加しました。加入数・死亡数や、一部の在籍人数ピークを確認できます。
- 新たに**39 MOD**に対応し、対応MOD数が**103件**になりました。既存対応MODの統計も拡充しています。
- 大量のセーブ取り込み、プロフィール保存、履歴データの保管を軽量化し、表示や一部MOD統計の不具合を修正しました。
- 配布ZIPに12言語の翻訳ファイルが含まれるよう修正しました。

[対応MOD一覧](https://github.com/pengin0503/Rimworld-Statistics/blob/v1.9.0/docs/supported-mods.md)

## English

### What's changed
- Added **per-colony history charts** with line graphs and overlays for comparing multiple colonies. Records without a verified save lineage are not connected as if they were continuous.
- Added **per-in-game-day comparisons** for eligible, fully recorded cumulative statistics.
- Save-import failures now show their reasons.
- Added **race and xenotype statistics**, including joins, deaths, and selected population peaks.
- Added support for **39 more mods**, bringing the total to **103 supported mods**, and expanded existing integrations.
- Reduced overhead when importing many saves, storing profiles, and maintaining history; fixed various display and mod-statistics issues.
- Fixed distribution packaging to include all 12 supported translations.

[Supported mods](https://github.com/pengin0503/Rimworld-Statistics/blob/v1.9.0/docs/supported-mods.md)
