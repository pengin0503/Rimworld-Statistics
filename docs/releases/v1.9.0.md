# Rimworld Statistics v1.9.0

RimWorld **1.7** と **Harmony** が必要です。

## 履歴グラフと診断・比較表示の拡張

- **コロニー別 履歴グラフ**（[#255](https://github.com/pengin0503/Rimworld-Statistics/pull/255), [#258](https://github.com/pengin0503/Rimworld-Statistics/pull/258), [#260](https://github.com/pengin0503/Rimworld-Statistics/pull/260), [#267](https://github.com/pengin0503/Rimworld-Statistics/pull/267), [#272](https://github.com/pengin0503/Rimworld-Statistics/pull/272)）：詳細統計の比較やコロニー行から、コロニーごとの時系列推移を折れ線グラフで確認できます（複数コロニーの重ね合わせ表示に対応、記録元が異なる組み合わせは区別して表示）。埋め込まれたチェックポイントから親子関係を確認できたセーブだけを線で結び、未確認の点は白抜きで表示します。系統が途切れる前の過去の記録や値に変化がない保存も系譜に残し、色見本つき凡例・欠測時点の目印・記録点数・最新セーブとの日付差の注記を追加しました。
- **1日あたりの比較表示**（[#260](https://github.com/pengin0503/Rimworld-Statistics/pull/260)）：完全に記録された加算可能なライブ合計の統計について、記録期間で割った1日あたりの値を比較表示と履歴ツールチップに表示します。
- **取込失敗の原因別診断**（[#260](https://github.com/pengin0503/Rimworld-Statistics/pull/260)）：セーブ取込の失敗を原因別（読込中に変更・開けない・破損・セーブでない・識別情報なし・予期しないエラー）に分類して件数を表示し、次回スキャン時の再読込の有無を案内します。

## 種族・ゼノタイプ統計

- 種族別の加入数（初加入の自由入植者）・入植者死亡数（[#256](https://github.com/pengin0503/Rimworld-Statistics/pull/256)）、種族別の在籍人数ピーク（自由入植者・囚人・奴隷）、Biotechゼノタイプ別の加入数・入植者死亡数を記録します（[#261](https://github.com/pengin0503/Rimworld-Statistics/pull/261)）。

## 修正と軽量化

- **表示・内訳ラベルの修正**（[#251](https://github.com/pengin0503/Rimworld-Statistics/pull/251)）：`packageId/DefName` 形式の内訳ラベルを詳細表・グラフで共通解決し、★ボタンとツールチップの重なりを解消、栄養量の単位を12言語へ翻訳しました。
- **1.7実DLLフック・Core契約の修正**（[#268](https://github.com/pengin0503/Rimworld-Statistics/pull/268), [#273](https://github.com/pengin0503/Rimworld-Statistics/pull/273)）：Sauridの卵出生・Phytokinの苗木出生フックの3引数ABIを修正しました。また、MOD統計のリビジョン番号がカウント登録時に引き継がれない不具合と、一部ファミリーの例外でチェックポイント観測全体が失われる不具合を修正しました。
- **ゲームスレッドを止めないプロフィール保存と書き込み最適化**（[#259](https://github.com/pengin0503/Rimworld-Statistics/pull/259), [#271](https://github.com/pengin0503/Rimworld-Statistics/pull/271), [#274](https://github.com/pengin0503/Rimworld-Statistics/pull/274)）：`RecordSave` のロック待ちを解消し、UTF-8バイト列のまま比較・直列化・書き込みを行う再利用バッファにより割り当てとロック保持時間を削減しました。
- **追加MODチェックポイントのアーカイブ対象化**（[#275](https://github.com/pengin0503/Rimworld-Statistics/pull/275)）：追加MODのチェックポイント統計も `checkpoint-archive/` へ安全に退避し、不要メタデータを削減するとともに、遅延コンフリクトや別分岐到着時はアーカイブから復元するようにしました。
- **大量セーブ取込・照合の最適化**（[#276](https://github.com/pengin0503/Rimworld-Statistics/pull/276)）：大量セーブ取込・チェックポイント更新・コロニー照合の二次的割り当てと全件走査を解消しました。
- **配布パッケージの修正**：12言語すべての `Keyed/*.xml` ファイルが配布ZIPに同梱されるよう修正しました。
