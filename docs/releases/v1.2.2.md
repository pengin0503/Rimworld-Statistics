# Rimworld Statistics v1.2.2

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony

## 日本語

### 主な変更
- 「詳細統計」で、保存済みの**実験的・未検証・不明な統計項目**を既定で表示するようにしました。
- 観測していない値は「—」や「不明」と表示し、0と区別します。
- 既存の統計記録と設定を引き継ぎます。**この変更は表示のみ**で、実験的な新規記録は引き続き既定OFFです。

## English

### What's changed
- Previously saved **experimental, unverified, and unknown statistics** are now shown by default in Detailed Statistics.
- Unobserved values display as a dash or Unknown, not zero.
- Existing records and preferences are preserved. **This only changes visibility**; new experimental recording remains off by default.
