# Rimworld Statistics v1.8.0

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony

## 日本語

### 主な変更
- 「詳細統計」の項目や「概要」のカードから、**コロニー別の棒グラフ**を表示できるようにしました。統計の内訳も確認できます。
- **10言語を追加**し、ゲーム内表示が日本語・英語を含む**12言語**に対応しました。
- **24 MODに27項目**の統計を追加しました。Set Up Camp、Animal Genetics (Continued)、Real Ruins、Hospitality関連などを含みます。

[対応MOD一覧](https://github.com/pengin0503/Rimworld-Statistics/blob/v1.8.0/docs/supported-mods.md)

## English

### What's changed
- Added **bar charts by colony** from Detailed Statistics and Overview cards, including breakdowns where available.
- Added **10 languages**, bringing in-game localization to **12 languages** including Japanese and English.
- Added **27 statistics across 24 mods**, including Set Up Camp, Animal Genetics (Continued), Real Ruins, and Hospitality-related mods.

[Supported mods](https://github.com/pengin0503/Rimworld-Statistics/blob/v1.8.0/docs/supported-mods.md)

[変更差分 / Full changes](https://github.com/pengin0503/Rimworld-Statistics/compare/v1.7.0...v1.8.0)
