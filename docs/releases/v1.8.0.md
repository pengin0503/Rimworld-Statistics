# Rimworld Statistics v1.8.0

RimWorld **1.7** と **Harmony** が必要です。

## 統計のグラフ表示

- 「詳細統計」の項目や「概要」の対応カードをクリックすると、コロニーごとの数値を棒グラフで比較できます。内訳がある統計では、項目別の数値も確認できます。

## 対応言語の拡大

- ドイツ語、フランス語、スペイン語（スペイン・ラテンアメリカ）、ポルトガル語（ポルトガル・ブラジル）、ロシア語、中国語（簡体字・繁体字）、韓国語のゲーム内表示を追加しました。
- 英語と日本語の表示も見直し、セーブ方式や統計の用語を整理しました。

## MOD固有の統計

- 24のMODにわたって27項目を追加しました。Set Up Camp、Animal Genetics (Continued)、Real Ruins、Hospitalityの追加MODなどの統計が含まれます。
- [対応MOD一覧](https://github.com/pengin0503/Rimworld-Statistics/blob/v1.8.0/docs/supported-mods.md)
