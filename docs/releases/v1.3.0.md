# Rimworld Statistics v1.3.0

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony

## 日本語

### 主な変更
- 既存セーブから、確認できる範囲の**派閥関係**と**所有拠点マップ数**を部分的に復元できるようにしました。
- セーブを変更せずに読み取る処理と、再スキャン時の更新・重複判定を改善しました。
- 親子関係を確認できるセーブについて、襲撃・入植者死亡数の区間差分を計算する基盤を追加しました。関係が不明なセーブは合算しません。
- **過去の出来事を完全に復元する機能ではありません。** 取得できない値は0ではなく「不明」と扱います。

## English

### What's changed
- Added **partial recovery** of faction relations and owned settlement-map counts from information present in older saves.
- Improved read-only save parsing, rescans, and duplicate handling.
- Added the groundwork for interval differences in raids and colonist deaths between saves with verified parent-child relationships. Unrelated or uncertain saves are not combined.
- **This does not reconstruct a complete event history.** Unavailable values remain unknown rather than being counted as zero.
