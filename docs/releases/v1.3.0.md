## Rimworld Statistics v1.3.0 (RimWorld 1.7)

全セーブ・全コロニーの記録をタイトル画面から集約するMODです。今回の正式版は、v1.2.2以降の**過去セーブ統計の限定的な復元**と、復元値の誤集計防止を中心とする更新です。

### v1.3.0の変更点

- **セーブに残るバニラ派閥情報の部分復元：** 保存時点で明示的に確認できる一部の友好／敵対関係、友好度の範囲を読み取り専用で取得します。対象は実証できるバニラ派閥に限定し、過去の外交イベント・全派閥・全期間の履歴とはみなしません。
- **拠点マップ数の部分復元：** 保存時点でプレイヤー所有の通常の入植地と証明できるマップを、実験的・部分的な下限値として記録します。画面上の「最大」系の統計名であっても、過去の全期間のピークを証明するものではありません。
- **SaveReader v9：** セーブを変更せず、必要な保存済み情報だけを上限付きで解析します。再スキャン時の読込更新、重複・欠損・曖昧な参照の保守的な扱い、取得できた過去の値の保持を改善しました。
- **チェックポイントの親子関係の検証基盤：** 直接の親子関係が保存データから証明できる場合に限り、襲撃・入植者死亡の**部分区間差分**を内部APIで計算します。分岐したセーブや関係不明のセーブ同士は連結しません。区間差分は**通算統計へ無条件に加算せず**、イベント発生時刻や完全な履歴も推測しません。
- 保存されていない値、判断できない値は **Unknown/不明** とし、0として扱いません。実験的な新規統計取得は従来どおり**既定OFF**です。

### 検証範囲

- .NET 10 Coreテスト：公開CIで**646件、失敗0件、8件は非公開実セーブがないためスキップ**。別途、提供された**実セーブ7件**を用いた受け入れテストでは**646件中644件成功、失敗0件、49件の別保存データを要する2件のみスキップ**。うち5件のチェックポイントの直接親子関係2区間を確認しました。
- Linux RimWorld **1.7.4985 rev1269** / WaylithClrのRimWorld-for-mod-testで、v1.3.0の基礎となるコード（`7f6d3df4`）の**MOD読み込み・初期化（A）と指定したHarmony Prefix 2件の登録（B）**を実ゲームで確認しました。詳細：[Actions #42730826777](https://github.com/pengin0503/RimWorld-for-mod-test/actions/runs/42730826777)。
- **未検証：** 実ゲームのタイトル画面での表示・操作、1.7.5000で作成された実セーブのゲーム内ロード、取得イベント全種類の正確性、長時間TPS・セーブ書込負荷、55件以上の実セーブ一括処理の性能。これらを実施済みと誤認しないでください。なお、上記の実セーブ受け入れは.NETの読み取り・インポートに対するもので、ゲーム内ロードではありません。
- 保存時点の情報に基づく復元は、当初候補とした41項目のうち**3項目のみ部分実装**です。残り38項目の復元、実際のイベント時刻や内訳の完全復元は含まれません。

### 導入・更新

- RimWorld 1.7向け。**Harmonyが必要**です。
- `RimworldStatistics-v1.3.0.zip`を導入・更新し、ゲームを再起動してください。配布物には開発用VerifyHarness、外部MOD別アドオン、テスト用原本セーブは含まれません。
- 既存のセーブや統計プロファイルの保全を前提に設計・検証していますが、更新前のバックアップを推奨します。新しい実験的記録を取得するには、MOD設定で対応する取得単位を明示的に有効化し、再起動してください。
