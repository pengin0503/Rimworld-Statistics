# Rimworld Statistics v1.2.0-rc.2

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony
**プレリリース / Pre-release**


## 日本語

### 主な変更
- セーブ取り込み失敗時の再試行とエラー表示を修正しました。
- セーブ分岐・チェックポイントの関係と保存履歴の保持を改善しました。
- 採掘では、実際に配置された採掘品だけを記録するよう修正しました。
- DLC未導入や記録欠落を「0」と誤認しないようにしました。
- 部屋・汚染の読み取り処理を軽量化しました。

### 注意
**プレリリース**です。追加した実験的な統計記録は既定OFFで、ゲーム内での正確性は十分に検証されていません。

## English

### What's changed
- Fixed retries and error reporting when save import fails.
- Improved tracking of save branches, checkpoint ancestry, and historical records.
- Mining statistics now count only items actually placed into the world.
- Missing DLC observations or incomplete records are not mistaken for zero.
- Reduced overhead in room and pollution calculations.

### Note
**Pre-release.** Newly added experimental recording remains off by default and has not been fully verified in game.
