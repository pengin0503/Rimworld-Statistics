# Rimworld Statistics v1.7.0

RimWorld **1.7** と **Harmony** が必要です。

## 統計の追加

- 対応するMODが導入されていれば、新規導入時は利用可能な統計を既定で取得します。保存済みの個別設定は引き継ぎます。取得対象はMOD設定から変更でき、ゲームの再起動は不要です。
- Vanilla Expandedシリーズ、Combat Extended、Gastronomy、Prison Expanded、RimefellerなどのMOD固有統計を追加しました。例として、実際に回収された食事代、刑期満了と囚人の退去、油田容量の減少と設備で消費した燃料を記録します。
- Vehicle Frameworkの所有車両数、Simple Warrantsの引き渡しと受取銀貨、Save Our Ship 2の軌道到達、A RimWorld of Magicの治癒成功などを追加しました。
- データ管理に「過去セーブの区間差分」を追加しました。親子関係と互換性を確認できたセーブ間で、敵襲・入植者死亡の増加を確認できます。分岐は個別に表示します。

## 修正と軽量化

- 途中導入・有効化時に、既存入植者の在籍期間と技能上昇の基準を誤って設定する問題を修正しました。
- バックアップ・復元とチェックポイント退避が同じファイルロックで排他されるようにしました。
- 取り込み時のプロフィール書き込み頻度と割り当てを抑え、履歴区間の照合を索引化しました。
- 「取得状況」に計測設定の変更を反映し、CSVの表示値に最多品目・記録コロニーを含めるようにしました。
- SDK経由の指標で重複排除の上限に達すると「取得状況」に表示します。

MOD連携の数値とゲーム内UIには実ゲームでの未確認項目があります。変更一覧は末尾の比較リンクから確認できます。
