# Rimworld Statistics v1.7.0

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony

## 日本語

### 主な変更
- 対応MODの統計は、初めて導入した場合に既定で記録できるようになりました。以前に保存した個別設定は維持します。設定の変更に再起動は不要です。
- Vanilla Expandedシリーズ、Combat Extended、Gastronomy、Prison Expanded、Rimefeller、Vehicle Framework、Simple Warrants、Save Our Ship 2などの**MOD固有統計**を追加しました。
- **過去セーブの区間差分**を追加しました。関係を確認できたセーブ間の襲撃・死亡数の増加を確認でき、分岐も区別します。
- 入植者の在籍期間・技能上昇の記録、CSV出力、取得状況の表示を修正しました。
- データ取り込み、プロフィール保存、履歴比較の処理を改善しました。

## English

### What's changed
- Supported mod statistics are now enabled by default for new installations when available. Existing individual preferences are preserved, and changes no longer require a restart.
- Added **mod-specific statistics** for Vanilla Expanded, Combat Extended, Gastronomy, Prison Expanded, Rimefeller, Vehicle Framework, Simple Warrants, Save Our Ship 2, and others.
- Added **interval differences between older saves** for raids and colonist deaths where save relationships can be verified. Save branches remain separate.
- Fixed colonist tenure and skill-gain baselines, CSV exports, and recording-status displays.
- Improved save imports, profile writes, and history comparisons.
