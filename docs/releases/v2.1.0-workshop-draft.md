## 日本語

```bbcode
[h1]Rimworld Statistics v2.1.0[/h1]
[b]対応バージョン：[/b]RimWorld 1.7 / [b]必須MOD：[/b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077]Harmony[/url]

[h2]v2.1.0 の主な変更[/h2]
[list]
[*][b]復元とバックアップの安全性：[/b]復元前の退避バックアップを保持対象から保護し、復元前に差分を確認できます。バックアップへのメモ、保持上限、ロック競合の再試行にも対応しました。
[*][b]記録の正確性：[/b]セーブの版判定を一本化し、「部分記録」の理由を細分化しました。読み取り中に変化したセーブは1回だけ再試行し、時刻の異常値は記録しません（1.8は未対応）。
[*][b]異常の可視化：[/b]プロフィール容量・外部変更・停止中プロバイダーを警告表示し、最新の有効なバックアップからの復旧を案内します。
[*][b]取り込みの改善：[/b]セーブの除外パターン、現存／アーカイブの内訳、追加・更新セーブのサマリ、1セーブだけの再検査、失敗セーブごとの操作、タイトル画面の進捗表示を追加しました。
[*][b]設定・取得状況・エンディング：[/b]検索、推奨設定の一括適用、記録ON/OFFの直接操作、種類フィルター、ガイド、二段階ツールチップを追加しました。
[*][b]表示状態と形式：[/b]詳細／ランキングの表示状態を保存し、出典フィルター、日数形式、桁区切り、0の非表示、AND・除外検索、定義式ポップオーバー、レート単位を利用できます。
[*][b]ダイアログとグラフ：[/b]最近使った項目、表示名の行内編集、現在コロニーの強調、ズームプリセット、年表の複数選択、区間／棒グラフ操作、確認ダイアログの統一を行いました。
[*][b]出力とエラー表示：[/b]CSVは従来どおりBOM付きで、出力フォルダー名の指定と「フォルダーを開く」、Markdown／TSVコピー、安定したエラーコード、更新後初回のみの新機能案内を追加しました。
[/list]

[h2]更新時の注意[/h2]
[list]
[*]既存のプロフィール・バックアップ・設定はそのまま読み込めます（v2.0.0のデータを読めます）。
[*]セーブの取り込みは読み取り専用です。除外パターンは次のスキャンから適用されます。
[*]RimWorld 1.8のセーブは未対応です。
[*]UI変更は自動テストで検証済みですが、実機確認はまだ行っていません。
[/list]
```

## English

```bbcode
[h1]Rimworld Statistics v2.1.0[/h1]
[b]Supported Version:[/b] RimWorld 1.7 / [b]Required Mod:[/b] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077]Harmony[/url]

[h2]What's changed in v2.1.0[/h2]
[list]
[*][b>Safer restore and backups:[/b] the pre-restore backup is protected from retention and a diff is shown before restoring. Added backup notes, retention limits and lock retries.
[*][b>More accurate records:[/b] centralized save-version gating, more specific partial-record reasons, one automatic retry when a save changes during reading, and time-anomaly guards (1.8 is still unsupported).
[*][b>Anomaly visibility:[/b] profile capacity, external changes and stopped providers are flagged, with guided recovery from the newest valid backup.
[*][b>Better import flow:[/b] save-name ignore patterns, present/archived counts, added/updated summaries, single-save recheck, per-failure actions and title-screen progress.
[*][b>Settings, coverage and endings:[/b] search, one-click recommended selection, direct recording toggles, ending-type filters, a guide and two-stage tooltips.
[*][b>Saved view state and formats:[/b] Details/Rankings state, source filter, day formats, number grouping, hide-zero, AND/exclude search, formula popover and rate units.
[*][b>Dialogs and charts:[/b] recent items, inline naming, current-colony marker, zoom presets, multi-select chronicles, interval/bar-chart controls and unified confirmations.
[*][b]Exports and errors:[/b] CSV exports keep their UTF-8 BOM and gained folder controls, Markdown/TSV copy, stable error codes and a one-time What's-new dialog.
[/list]

[h2]Updating[/h2]
[list]
[*]Existing profiles, backups and settings load unchanged; v2.0.0 data remains readable.
[*]Save importing is read-only. Ignore patterns apply from the next scan.
[*]RimWorld 1.8 saves are not supported.
[*]UI changes are test-verified but not yet checked on a real device.
[/list]
```
