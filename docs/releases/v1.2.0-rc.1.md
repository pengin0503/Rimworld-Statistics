# Rimworld Statistics v1.2.0-rc.1

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony
**プレリリース / Pre-release**


## 日本語

### 主な変更
- 薬物離脱の開始、入院、物資不足のない期間、栽培区画の収穫、古代の脅威の発見、帝国のクエスト、エンディング時の人数など、詳細統計の取得候補を拡充しました。
- セーブとチェックポイントの保存処理、Odysseyの飛行記録を改善しました。

### 注意
**プレリリース**です。追加した記録機能はゲーム内で未検証のため既定OFFです。

## English

### What's changed
- Expanded experimental statistics for withdrawal onset, hospital stays, shortage-free periods, growing-area yields, ancient dangers, Empire quests, and ending party size.
- Improved save/checkpoint preservation and Odyssey flight tracking.

### Note
**Pre-release.** The newly added recording features had not been verified in game and remain off by default.
