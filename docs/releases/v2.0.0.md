# Rimworld Statistics v2.0.0

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony

## 日本語

### 主な変更
- **コロニー総括レポート**を追加しました。コロニーごとの主要な成績と順位をまとめて表示し、オフラインで閲覧できるHTMLにも出力できます。プレイ中のメニューからは、現在のコロニーの総括を直接開けます。
- **コロニー年表**を追加しました。エンディング、最初の加入・敵襲・死亡などの節目、研究完了、メカニターボスの撃破を時系列で表示します。文字検索とゲーム内日数での絞り込み、Markdown・HTMLへの出力に対応しています。セーブに残っている入植・結婚・大きな脅威の記録も補助的に表示します。
- **セーブ系統**ビューを追加しました。同じコロニーのセーブの親子関係と、セーブ＆ロードによる分岐を確認できます。
- コロニーを比較する**散布図**を追加しました。縦軸と横軸に統計を1つずつ選び、ストーリーテラーや難易度などで点を色分けできます。
- 条件でコロニーを自動的にまとめる**スマートグループ**を追加しました（ストーリーテラー、難易度、パーマデス、エンディング到達、生存日数、開始バイオームなど）。1日あたりの値への切り替えを、比較・ランキング・散布図にも広げました。
- コロニー別履歴グラフに、期間の拡大表示、グラフ上の2点を選んでその間の変化を表示する機能、お気に入り登録を追加しました。点が多い場合も、最大値と最小値を保ったまま描画します。
- コロニーに表示名を付けられるようにし、コロニーの選択画面に検索を追加しました。統計ウィンドウを開くキーボードショートカットも設定できます。
- **公式DLCの統計を拡充**しました。Anomaly（心霊儀式、エンティティの収容・脱走、モノリス）、Biotech（メカニターボスの召喚・撃破、成長槽、遺伝子の抽出・合成・移植）、Odyssey（グラヴシップ、軌道への到達、ランドマークの訪問）、Ideology、Royaltyが対象です。一部の項目は過去のセーブからも復元します。
- 新たに**6 MOD**（Prison Labor、MedPod、Alpha Implants、Biomes! Islands、RimQuest (Continued)、Horrors (Continued)）に対応し、対応MOD数が**109件**になりました。既存の対応MOD 8件にも統計を追加しました。
- 出力を拡充しました。時系列の履歴CSV、元の派閥名の列、個人情報を含まない匿名診断サマリを追加しました。すべてのセーブを読み直して記録と照合する「強制再検査」も追加しました。
- 外部連携SDKをv1.2に更新しました。既存の連携MODはそのまま動作します。
- 読み込み時の安定性、集計、表示、12言語の訳文について、**39件**の不具合修正や改善を行いました（v1.9.1以降に完了したIssueのうち、新機能と開発者向けの項目を除いた数）。

### 更新時の注意
- 更新後の最初の取り込みで、残っているすべてのセーブを新しい方式で読み直します。セーブが多い場合は時間がかかります。セーブファイルは変更しません。
- 新しく追加した記録型の統計は、更新後のプレイから記録されます。
- 囚人に作業させるMOD（Prison Laborなど）を使っている場合、作業系の統計にコロニーの囚人の作業も数えるようになりました。v1.9.x から続くコロニーでは、囚人の作業を数えた時点で、その統計を部分記録（下限値）として表示します。

## English

### What's changed
- Added **colony summary reports**, which gather each colony's key results and rankings and can be exported as offline HTML. The in-game menu opens the current colony's summary directly.
- Added **colony chronicles**, a timeline of endings, milestones such as the first join, raid and death, completed research, and mechanitor boss defeats. They support text search, filtering by in-game day, and Markdown/HTML export. Settlement, marriage and major-threat records kept in saves are shown as supplementary entries.
- Added a **save lineage** view that shows how a colony's saves descend from each other and where save-and-reload created branches.
- Added a **scatter plot** for comparing colonies, with one statistic on each axis and dots colored by storyteller, difficulty and other attributes.
- Added **smart groups** that collect colonies automatically by storyteller, difficulty, permadeath, reached endings, days survived, starting biome and more. The per-day view now also covers comparisons, rankings and the scatter plot.
- Colony history charts gained range zoom, the change between two points picked on the chart, and Favorites. Dense charts keep their true maximum and minimum values.
- Colonies can be given display names, and colony pickers can be searched. Keyboard shortcuts for the statistics windows can be configured.
- **Expanded official DLC statistics**: Anomaly (psychic rituals, entity containment and escapes, the monolith), Biotech (mechanitor boss summons and defeats, growth vats, gene extraction, assembly and implantation), Odyssey (gravships, reaching orbit, landmark visits), Ideology and Royalty. Some of them are also restored from older saves.
- Added support for **6 more mods** (Prison Labor, MedPod, Alpha Implants, Biomes! Islands, RimQuest (Continued), Horrors (Continued)), bringing the total to **109 supported mods**, and added statistics for 8 already supported mods.
- Expanded exports with a time-series history CSV, an original faction name column, and an anonymous diagnostic summary that contains no personal information. Added a "Full re-check" that reads every save again and compares it with its record.
- Updated the external integration SDK to v1.2. Existing integration mods keep working unchanged.
- Made **39** fixes and improvements to loading stability, aggregation, display and wording across the 12 languages (issues completed since v1.9.1, excluding new features and developer-only items).

### Updating
- The first import after updating reads every remaining save again with the new reader. With many saves this takes a while. Save files are not modified.
- Newly added live statistics are recorded from play after the update.
- If a mod lets prisoners work (such as Prison Labor), work statistics now include work by the colony's prisoners. For colonies continued from v1.9.x, those statistics are shown as a partial record (a lower bound) once a prisoner's work has been counted.
