# Rimworld Statistics v1.2.0-rc.4

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony
**プレリリース / Pre-release**


## 日本語

### 主な変更
- 外部MOD向け統計SDKの**イベント記録処理を軽量化**しました。イベントの重複判定や保存形式は維持しています。
- SDKによる統計記録とセーブ履歴への連携を引き続き試験できます。

### 軽量化の測定結果
- **重複イベント：352 → 152バイト/件**（割り当て量約**57%減**）。
- **新規イベント：634.8 → 331.2バイト/件**（割り当て量約**48%減**）。
- GitHub Actions上のゲーム外マイクロベンチマーク2回による値です。CPU時間の結果にはばらつきがあり、**RimWorldのTPS改善を示すものではありません**。

### 注意
**プレリリース**です。外部SDKは実験的で、実ゲームでの動作・長時間性能は未確認です。通常プレイには本体ZIPを使用し、SDKサンプルは必要な場合だけ導入してください。

## English

### What's changed
- **Reduced memory allocations** in the external mod statistics SDK's event-recording path while preserving event deduplication and saved data formats.
- The experimental SDK can still be used to test statistics collection and save-history integration.

### Measured performance
- **Duplicate events: 352 → 152 bytes/event** (about **57% fewer allocations**).
- **New events: 634.8 → 331.2 bytes/event** (about **48% fewer allocations**).
- Results come from two offline microbenchmark runs in GitHub Actions. CPU timings varied; these results **do not measure RimWorld TPS improvements**.

### Note
**Pre-release.** The external SDK is experimental; in-game behavior and long-running performance were not validated. Use the main mod ZIP for normal play; the SDK sample is optional.
