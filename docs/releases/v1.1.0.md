# Rimworld Statistics v1.1.0

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony

## 日本語

### 主な変更
- タイトル画面の「通算統計」に**詳細統計**を追加しました。資産、人口、心情、襲撃、クエストなどを全コロニーまたは個別に確認できます。
- 最大人口、最速エンディング、実プレイ時間などのランキングを追加しました。
- 旧バージョンの統計記録を引き継ぎ、移行前のプロフィールをバックアップします。

### 性能について
- 当時の計測では、**初回取り込み時間が従来の1.18～1.30倍**でした。これは処理時間の増加であり、軽量化の数値ではありません。

## English

### What's changed
- Added **Detailed Statistics** to the title-screen lifetime statistics view, including wealth, population, mood, raids, and quests by colony or overall.
- Added rankings such as peak population, fastest ending, and play time.
- Preserves older statistics records and backs up the pre-migration profile.

### Performance note
- Measurements at the time showed **initial import taking 1.18–1.30× as long as before**. This indicates increased import time, not a speed improvement.
