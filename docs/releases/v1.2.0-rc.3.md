# Rimworld Statistics v1.2.0-rc.3

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony
**プレリリース / Pre-release**


## 日本語

### 主な変更
- 外部MODがRimworld Statisticsへ独自の統計を送るための**実験的なSDK**を追加しました。
- イベント件数・合計・平均と保存時点の数値を扱い、記録済みのセーブ履歴へ統合できます。
- 重複イベントの防止、記録エラーの隔離、依存先が存在しない場合の安全な処理に対応しました。
- 保存済みデータの互換性や、統計名の大文字・小文字の違いによる重複集計を修正しました。

### 注意
**プレリリース**です。SDKの互換性と実ゲームでの動作は保証されません。通常プレイにはSDKサンプルは不要です。

## English

### What's changed
- Added an **experimental SDK** for other mods to submit their own statistics to Rimworld Statistics.
- Supports event counts, sums, averages, and save-time snapshots linked to existing save history.
- Added event deduplication, isolated recording failures, and safe behavior when the host mod is unavailable.
- Fixed compatibility issues with saved data and case changes in statistic names.

### Note
**Pre-release.** SDK compatibility and in-game behavior are not guaranteed. The SDK sample is not needed for normal play.
