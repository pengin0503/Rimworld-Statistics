## Rimworld Statistics v1.4.0 — RimWorld 1.7

全セーブ・全コロニーの統計をタイトル画面にまとめるMODの更新です。**新しい通算記録の収集機能には実ゲームで未検証のものがあります。** ユーザーの明示的な公開指示により、追加の実ゲーム受け入れ検証を完了しないまま正式リリースします。**実験的取得機能は引き続き既定でOFF**です。

### 主な変更

- **全コロニー横断の比較統計を84項目追加：** 既存331定義を維持し、計415定義。作物別収穫量、品目別売却・購入数の最多品目、人数・在庫・発電機・研究・医療・資産・外交・一部DLCのコロニー間最多／最少などを、利用可能な保存済み観測値から計算します。詳細は[集計の仕様・検証](https://github.com/pengin0503/Rimworld-Statistics/blob/v1.4.0/docs/research/2026-11-10-cross-colony-implementation-verification.md)。
- **通算統計の整理：** 「通算（記録範囲内）」「その他」「すべて」を切り替えられます。取得済みの品目別内訳や交易形態の内訳を展開できます。記録されていない期間のイベントや欠測を0とみなしません。
- **P1/P2の実験的取得候補：** 製作・採掘の種類別実績、清掃・消火・食事・運搬などの成功条件に基づいた収集コードが含まれます。これらの実イベントでの正確性と長時間性能は未検証で、利用者が明示的にONにした場合のみ記録対象となります。
- **詳細統計の見やすさ：** 「数値のある項目のみ」の絞り込みを追加。観測済みの0やPartialの実数値は残し、Unknownなどの未測定行は除外できます。最多品目が確定できない場合は「未達成」と区別して表示します。日本語・英語に対応。
- **後方互換：** 保存キー・既存統計・プロフィールを維持し、同一コロニーの複数セーブや分岐の独立した二重合算を回避する設計です。横断集計には既存の代表観測を使用します。

### 未検証・制限事項

- コア単体テスト、既存CIでのビルド、翻訳キー検査と配布ZIP検査は実施していますが、これらは実ゲームでの各イベント取得の正確性を保証しません。
- 新しい取得フック全件の実ゲーム正負ケース、実ゲームでの保存・ロード往復、すべてのDLC/MOD組み合わせ、継続稼働時のTPS・GC割当・保存処理時間、35件の実セーブ一括再取込、最新版のUI操作確認は**未完了**です。
- 実機DPAログではRimworld Statisticsの主要な性能障害を特定していません。ただし、計測条件の揃った有効／無効A/B比較ではなく、統計取り込みや保存処理全体の負荷を証明しません。[調査記録](https://github.com/pengin0503/Rimworld-Statistics/blob/v1.4.0/docs/research/2026-11-10-user-dpa-and-coverage-audit.md)。
- 以前のセーブに保存されていないイベント履歴を復元することはできません。最新の値を各セーブから再取得するだけでは、過去イベントの通算にはなりません。Partial・Unknown・NotApplicableは区別されます。
- このリリースは新規統計全項目を「検証済み」に昇格させるものではありません。実験的な記録はリスクを理解した上で個別に選択してください。

### 導入

- 対応ゲーム：**RimWorld 1.7**。必須MOD：**Harmony**（Workshop ID `2009463077`）。
- 配布ZIPを展開し、`RimworldStatistics` フォルダを `Mods` に配置してゲームを再起動してください。更新前のセーブとプロフィールのバックアップを推奨します。
- `RimworldStatistics-v1.4.0.zip` は通常使用向けMODのみです。開発用VerifyHarness、非公開実セーブ、外部MOD用アドオンは同梱しません。
