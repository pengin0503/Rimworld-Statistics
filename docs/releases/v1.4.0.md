# Rimworld Statistics v1.4.0

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony

## 日本語

### 主な変更
- コロニー間の最多・最少記録や品目別の記録など、**比較統計を84項目追加**しました。統計定義は**331 → 415項目**になりました。
- 「通算（記録範囲内）」「その他」「すべて」の表示を切り替え、品目別・取引別の内訳を確認できるようにしました。
- 「**数値のある項目のみ**」の絞り込みを追加しました。
- 製作・採掘・作業などの実験的な記録項目を拡充しました。**新しい実験的取得は既定OFF**です。
- 記録がない期間の出来事や不明な値を、誤って0として集計しないようにしています。

## English

### What's changed
- Added **84 cross-colony comparison statistics**, including category leaders and colony highs/lows, expanding the catalog from **331 to 415 entries**.
- Added lifetime/other/all views and breakdowns by item and trade type.
- Added a **show only statistics with values** filter.
- Expanded experimental recording for crafting, mining, and other activities. **New experimental collection remains off by default.**
- Missing history and unknown observations are not treated as confirmed zeros.
