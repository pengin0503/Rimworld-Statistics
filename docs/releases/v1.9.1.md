# Rimworld Statistics v1.9.1

RimWorld **1.7** と **Harmony** が必要です。

## 修正と改善

- **未導入MODの統計設定と初期状態の整理**（[#278](https://github.com/pengin0503/Rimworld-Statistics/issues/278), [#282](https://github.com/pengin0503/Rimworld-Statistics/pull/282)）：対応MODの統計ユニット（`UnitRecordingStates`）について、対象MOD本体が現在のMOD構成に読み込まれていない場合は、未設定時に既定で無効として扱い、MOD設定画面では「対象MOD未導入」と表示してチェックボックスを無効化するように改善しました。
- **履歴グラフの間引きとホバー・描画の整合性修正**（[#279](https://github.com/pengin0503/Rimworld-Statistics/issues/279), [#282](https://github.com/pengin0503/Rimworld-Statistics/pull/282)）：コロニー別履歴グラフで同一値の中間チェックポイントを間引く際、間引かれた点が `ChartPoints` に残って存在しない座標へのホバー判定や不自然な線分描画が発生する不具合を修正しました。あわせて、確定した親子関係をまたいで間引いた場合も実線接続を維持するように改善しました。
- **概要タブのお気に入りピン留めの改善**（[#280](https://github.com/pengin0503/Rimworld-Statistics/issues/280), [#282](https://github.com/pengin0503/Rimworld-Statistics/pull/282)）：MOD設定で非表示にした統計がお気に入り欄に「利用できなくなりました」と残る問題を解消し、ピン留めした詳細統計の項目をクリックすると詳細統計タブの該当項目・内訳へ直接移動できるようにしました。
- **UIエッジケースの修正**（[#281](https://github.com/pengin0503/Rimworld-Statistics/issues/281), [#282](https://github.com/pengin0503/Rimworld-Statistics/pull/282)）：
  - コロニー別履歴グラフの重ね合わせ選択をクリアした際、スクロール位置もリセットするように修正しました。
  - コロニーグループ編集ダイアログを再度開いた際、前回の入力文字列やスクロール位置が残らないように修正しました。
  - 内訳の比率バー表示で、端数丸めにより複数セグメントの合計幅がバーの右端をわずかに超える場合がある問題を修正しました。
  - コロニー一覧タブで、行の入れ替え操作と詳細統計への遷移が同じフレームで競合しないように修正しました。
- **全12言語の翻訳表現と用語統一の改善**：
  - `World Domination 2.0` の勝利保持説明を全12言語で統一しました。
  - ポルトガル語（欧州・ブラジル）、スペイン語（ラテンアメリカ）、中国語（簡体字・繁体字）、韓国語、ドイツ語において、RimWorld公式訳語（俘虜・電池・은・생물군계・수감자など）や地域表記（`gravação`・`agregada`・ギュメ表記・冠詞縮約・性数一致など）を自然な表現に統一しました。
