# Rimworld Statistics v1.2.0

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony

## 日本語

### 主な変更
- 全セーブの通算統計と詳細統計を拡張し、セーブ・チェックポイントの履歴を保存・表示できるようにしました。
- **264項目の実験的な取得候補**を追加しました。これらの新規記録は既定OFFで、利用する場合はMOD設定から有効化します。
- HospitalityやRimworld-Recruitment向けの実験的な連携と、外部MOD向け統計SDKを追加しました。
- 部屋や汚染に関する統計の計算処理を改善しました。

**配布物:** プレイ用はRimworldStatisticsのZIPです。StatisticsSdkSampleは開発者向けのサンプルで、通常プレイには不要です。

## English

### What's changed
- Expanded lifetime statistics, detailed metrics, and saved history/checkpoints across colonies.
- Added **264 experimental collection entries**. These are off by default and must be enabled in mod settings.
- Added experimental integration for Hospitality and Rimworld-Recruitment and an external statistics SDK for mod authors.
- Improved room- and pollution-related calculation paths.

**Downloads:** Install the RimworldStatistics ZIP for normal play. StatisticsSdkSample is a developer sample and is not needed to play.
