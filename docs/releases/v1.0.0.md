# Rimworld Statistics v1.0.0

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony

## 日本語

### 初回リリース
- タイトル画面から、全セーブ・全コロニーの**通算ゲーム内日数、資産、襲撃、人口、実プレイ時間、エンディング**などを確認できます。
- RimWorld **1.5～1.7の既存セーブ**を読み取り専用で取り込みます。
- 同じコロニーの複数セーブや上書き保存を識別し、履歴を保持します。
- 日本語と英語に対応し、取り込みの進捗表示、キャンセル、再スキャン、プロフィールのバックアップを利用できます。

## English

### Initial release
- View **total game days, wealth, raids, population, play time, endings**, and other lifetime statistics across all saves and colonies from the title screen.
- Read-only import of existing RimWorld **1.5–1.7 saves**.
- Preserves colony identity and history across multiple saves and overwritten save files.
- Includes Japanese and English, import progress, cancellation, rescans, and profile backups.
