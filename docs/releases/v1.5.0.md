# Rimworld Statistics v1.5.0

**言語 / Language:** [日本語](#日本語) | [English](#english)

**対応 / Requirements:** RimWorld 1.7 · Harmony

## 日本語

### 主な変更
- 個別に配布していたMOD統計アドオンを**Rimworld Statistics本体に統合**しました。別途統計アドオンを導入する必要はありません。
- **Hospitality (Continued)**：来訪客・グループ、宿泊客の加入、ゲスト用ベッドなど。
- **Rimworld-Recruitment**：募集開始数、支払い銀貨、予定応募人数など。
- **Dubs Bad Hygiene**：貯水量、タンク容量、設備の名目給水能力。
- **Smart Apparel Upgrade**：自動着替えジョブの発行回数。
- 既存の記録を保持します。**新しいMOD統計の記録はこの版では既定OFF**です。

### 更新時の注意
以前の**統計アドオン**を無効化・削除してください。HospitalityなどのゲームプレイMOD自体を削除する必要はありません。

## English

### What's changed
- **Integrated separately distributed mod-statistics add-ons** into Rimworld Statistics. Separate statistics add-ons are no longer required.
- **Hospitality (Continued):** guest and group information, guest recruitment, and guest beds.
- **Rimworld-Recruitment:** recruitment starts, silver spent, and expected applicant counts.
- **Dubs Bad Hygiene:** stored water, tank capacity, and nominal supply capacity.
- **Smart Apparel Upgrade:** automatic outfit-change jobs issued.
- Existing records are retained. **New mod-statistics recording remains off by default in this version.**

### Updating
Disable or remove the **old statistics add-ons**. Do not remove the gameplay mods themselves, such as Hospitality, unless you no longer use them.
