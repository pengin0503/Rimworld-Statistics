# Rimworld Statistics v1.5.0 — MOD統計対応初期版

RimWorld 1.7向けの**本体一体型MOD統計対応初期リリース**です。従来別々に配布していた統計アドオンの取得処理を、Rimworld Statistics本体に統合しました。**統計アドオンの追加インストールは不要です。** 既存の全セーブ・全コロニー横断統計やプロフィール保存方式は引き継ぎます。

## MOD対応の主な変更

- **Hospitality (Continued)**：ゲスト・グループ数、ゲストへ割当済みのベッド数（保存時）、来訪グループ／来訪客の累計、宿泊客の加入成功回数（強制／任意の内訳）。
- **Rimworld-Recruitment**：進行中の募集数、募集開始の累計、実際に支払った銀の累計、募集開始時に抽選された**予定応募人数**の累計（実際の到着・加入人数ではありません）。
- **Dubs Bad Hygiene**：配管接続の貯水量・タンク容量（L）、ポンプ・地下水の**名目供給能力**（L/ゲーム内日）。供給能力は実際の水の生産量・消費量の累計ではありません。
- **Smart Apparel Upgrade**：自動着替えのWearジョブを**発行した回数**（着替えの完了回数ではありません）。

4つの統合アダプターは**17個の既存・追加済みの安定した統計ID**を使用します。日本語・英語の項目説明も本体内に収録しました。各ゲームプレイMODは必須ではなく、対応するMODがない場合はフックを適用しません。

### 対応ソースの範囲

RimWorld **1.7**に対応。今回の実装がソース・DLL照合した対象は、Hospitality (Continued) **1.1.8**、Rimworld-Recruitment **1.1.2**、Dubs Bad Hygiene **3.2.3260**、Smart Apparel Upgrade **1.0.1**です。取得ごとに対象のAPI・必要なバージョンを確認し、適合しない取得処理は無効化する方針です。**他の版で取得できることを保証しません。**

## 旧アドオンからの移行

1. 既存のセーブデータとRimworld Statisticsのプロフィールをバックアップしてください。
2. Rimworld Statistics本体をv1.5.0に更新し、従来の統計アドオン（Hospitality／Recruitment／Dubs Bad Hygiene／Smart Apparel Upgrade用）を**無効化・削除**してください。統計の対象となるゲームプレイMOD自体は、引き続き必要に応じて有効にします。
3. HarmonyとRimworld Statisticsを有効にし、ゲームを再起動してください。
4. 実験的な取得を利用する場合はRimworld StatisticsのMOD設定で対応する`mod.<owner>.<family>`を明示的に有効化し、再起動してください。

旧アドオンが導入されたままの場合、同一対象に対して本体内蔵のフックを停止する移行ガードを設けています。**記録済みの数値・統計ID・来歴は本体プロフィールに維持され、対象MODや旧統計アドオンを削除しても消えません。** 対象がない期間の新規イベントは取得できません。未知の値を0として補完しません。また旧版の募集開始系列と新しい系列は、重複回避方式が異なるため別々に保持し、勝手に合計しません。

## 検証状況・既知の制約

- 本体統合PR [#103](https://github.com/pengin0503/Rimworld-Statistics/pull/103)をマージし、mainの[統合CI #42957658567](https://github.com/pengin0503/Rimworld-Statistics/actions/runs/42957658567)でCoreテスト、対象MODの固定ソース／DLL互換性、17統計IDの維持、日本語・英語翻訳、配布ZIP内のDLL所有、Windows検証起動補助を確認しました。
- **RimWorld実ゲームでの全MODの数値照合、セーブ・ロード後の実イベント再現、長時間のTPS・GC・保存時間測定は未完了です。** そのため、MOD固有の取得機能は**実験的で既定OFF**のままです。新規統計の実測値について完全性・正確性を保証するリリースではありません。
- イベント履歴が以前のセーブに存在しない場合、アドオン・本体導入以前の実績を推測・復元しません。全コロニー横断の集計は、実際に保存された観測値とその範囲に基づきます。

## ダウンロード・導入条件

- 必須：**RimWorld 1.7、Harmony**（Steam Workshop ID `2009463077`）
- 配布ファイル：`RimworldStatistics-v1.5.0.zip`、SHA-256検証用`RimworldStatistics-v1.5.0.sha256`
- ZIPを展開し、`RimworldStatistics`フォルダをRimWorldの`Mods`フォルダに配置してください。更新後はRimWorldを再起動してください。
- 配布ZIPに収録するDLLは本体の`RimworldStatistics.dll`、`RimworldStatistics.Core.dll`、`RimworldStatistics.Api.dll`のみです。外部ゲームプレイMODのDLL、個別統計アドオン、開発用検証ハーネス、非公開セーブは含まれません。
