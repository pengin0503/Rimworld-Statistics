The 35 rows correspond to the [master register](README.md). Execute the specified first slice for **Ready** rows in [handoff order](2026-11-13-implementation-handoff.md). **Conditional** rows identify one remaining proof and an acceptance condition. **Input needed** rows need the identified release asset. **Generic / no new key** records coverage or a declined proposal with evidence. Priority follows the existing [Workshop reach snapshot](2026-11-12-popularity-priority.md) among eligible rows. An unverified outcome stays in the register without a metric key. [Upstream revisions and load paths](2026-11-13-reference-lock.md) are pinned separately.
