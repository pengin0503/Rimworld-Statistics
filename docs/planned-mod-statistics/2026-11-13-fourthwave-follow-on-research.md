## Ranking for the next focused code-level investigation

1. **H03 Real Ruins** — unusually clear source identity (ruin scanner vs actual site entry), complements whole-save exploration/history; use only metadata and do not create network requests.
2. **H05 Biomes! Bees** — clean, dedicated 1.7 DLL and a dedicated pollination completion action; however actual growth delta needs checking, and bulk per-job overhead must be low.
3. **H01 AES School+** — novel school administration outcomes, but secure exact 1.7 source/commit before patching.
4. **H02 Go Explore!** — very popular, but its 1.7 quests may already be covered generically; implement only separately provable MOD-specific success.
5. **H04 RimCities unofficial** — hold until better supported 1.7 edition and reliable city/citadel outcome.

## Reviewed and not added as extra required metrics

- **Dynamic Diplomacy - Continued** [Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3220299022): official page currently lists only through **1.6**. Host already has broad quest/reputation counters and G01–G02 cover diplomacy; **hold** without 1.7 binary or distinctive event.
- **Walk Around Park** [Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3775681844): park outings/dates/picnics would be a distinct social/recreation category, but inspected Workshop listing is **1.6 only**. **Hold until 1.7**; do not count visits via current visitors/quality snapshots.
- **[HAS] Pestilence & Physic** [Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3772650173): an interesting infectious-transmission/epidemiology genre, but listed **1.6 only**; no 1.7 success event or distinguishing infection-onset route audited. **Hold**.
- **Museums** [Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3204176859): 1.4–1.6 only on inspected listing and overlaps G06's museum jobs. **Hold / avoid duplicates**.
- **Ordinary production, honey manufacturing and item acquisition**: generic events already cover these where validated. Avoid manufacturing statistics under H05 just because a beekeeping MOD is popular.

**Required integration protocol:** compare proposed events against existing metric key families, inspect *actual selected* 1.7 binary, define success and stable lineage/point identity, test load/checkpoint/branch replays and explicit settings opt-outs, and keep optional hook overhead negligible. No presumption that every proposed submetric will be delivered. For outcomes with no trustworthy commit site, waive rather than infer. No code, release, or Steam changes in this documentation PR.
