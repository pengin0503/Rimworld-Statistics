# Implementation status for the 27 additional MOD candidates

This register covers the 27 candidates retained after the original 35-MOD plan. It records 27 new statistics across 24 MODs. Each integrated row lists the first event implemented and any remaining proposals. Public source and selected DLL metadata/IL were examined for the implemented events. The Vehicle Framework binary came from the previously supplied 1.7 package. The game was not launched.

The host uses the existing optional acquisition settings, localized descriptors and checkpoint aggregation. Counts use a representative timeline per colony and add independent colonies. Disabled, absent or incompatible targets use the existing coverage handling. Target DLLs are not distributed with Rimworld Statistics.
