# New MOD statistics candidates — third-wave register (2026-11-13)

## Scope and invariants

This is an **append-only candidate register separate from the existing 35-candidate plan**, introduced after main `ac0fcab959e280af405a282e00c91eb314de147f`. None of these proposals is a committed or released statistic. Do not renumber the 35 prior IDs. A `source inspected` mark confirms inspection of selected public source only, **not** proof of the exact binary selected by the RimWorld 1.7 loader or a successful Harmony installation. Inspect actual `loadFolders.xml`, package ID, active 1.7 assembly and the final success site before coding.

The integration architecture stays in the Rimworld-Statistics host. Preserve lifetime/checkpoint branch semantics, existing readings when optional mods disappear, explicit OFF settings and ON-by-default for new integrations. No repeated scans of all objects/ticks. Prefer a successful action (or a positive delta at its exact commit), not attempts, messages, current stocks or nominal capacity; do not duplicate vanilla or generic ThingDef/pawn/trade/quest counters. **User permits waiving difficult-to-measure outcomes rather than recording a proxy**: [decision](2026-11-13-evidence-gated-outcome-disposition.md).
