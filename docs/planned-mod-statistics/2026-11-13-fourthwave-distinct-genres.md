# Fourth-wave: distinct categories of MOD statistics (2026-11-13)

**Purpose:** preserve seven candidates following the 35 approved original MODs and the 16 candidates in [E01–E08](2026-11-13-thirdwave-candidate-register.md) and [F01–F08](2026-11-13-non-ve-discovery.md). These seven entries (G01–G07) represent **new categories of lifetime statistics**. See the [implementation status](2026-11-13-additional-30-implementation.md) for selected outcomes. This file is research and potential implementation scope only. [Fifth-wave follow-up](2026-11-13-fourthwave-follow-on-research.md) holds the additional discoveries.

**Evidence tiers:**
- **Source-confirmed (candidate)** = named public source class and a plausible commit site inspected, but **not** proof of running the exact 1.7 assembly, patch safety, or correctness in game.
- **Published feature (candidate)** = official/Workshop description, 1.7 support indicated, but no outcome code inspected. Do not implement solely on this evidence.
- **Hold** = relevant distinct mechanic, but compatibility, outcome, or loaded source cannot be established.

**Shared acceptance contract:** only count actual **committed gameplay outcomes**, with colony/game-lineage persistence and checkpoint deduplication. Classify by semantic event, preserve optional-mod history after removal and do not add Anomaly dependencies. Mod absent means unknown/not collected, not zero; existing user's opt-outs remain. Never count save-load initialization, debug actions, UI clicks, attempted operations, stock snapshots or normal generic quest/trade/build/ritual/birth records as new independent lifetime events. Use host's existing optional integration system, performance-safe patching; waive unreliable submetrics per [owner decision](2026-11-13-evidence-gated-outcome-disposition.md). All Workshop URLs below refer to the inspected 2026-11-13 research, not a guarantee about a particular user's installed binary.

## Implementation sequencing by evidence rather than superficial popularity

- **Best immediately inspectable source**: G04 (actual `EndBrawl` outcome), G07 (specific funeral outcome), G06 (museum job pathway), G05 (birth context only; confirm success site).
- **Strong novel concepts awaiting 1.7 binaries**: G03 (semesters), G01 (treaties), G02 (vassals).
- The addition of these ideas **does not mandate implementing every submetric**: discard those without precise, inexpensive success evidence, and use an explicit waiver instead of a guessed proxy.
