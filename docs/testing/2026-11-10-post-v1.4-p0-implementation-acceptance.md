## Completed implementation (P0-A, P0-B)

- `MetricAvailabilityPolicy` classifies **no applicable**, **none observed**, **some observed**, and **all observed** from available independent-colony counts. It does **not** assert why capture is absent. A numeric payload with Unknown coverage is not treated as measured. Saved-capture Partial or positive sinceTick warns about incomplete periods.
- `CrossColonyAggregator.TopType` retains every existing top-one derived key/value and now carries all measured by-type quantities in descending stable order. Each rank has **measured per-colony contributions** as nested child rows; no new persisted metric, checkpoint family, hook, profile field or reader version.
- Unknown, NotApplicable, untrusted split values, duplicate breakdown keys and nonfinite totals do not become invented winners. Partial/unknown buckets and unreconciled source scalars keep incomplete result status. No sum of five same-campaign save files.
- Details UI exposes an expandable full ranking and a second-level per-colony contribution list using current colony labels and fallback Def names; category breakdown labels reuse source metrics' translations. New Japanese and English explanatory strings.
- Synthetic xUnit regressions cover two independent colonies, deterministic ties, duplicate breakdowns, missing value versus observed zero, N/A, unknown numeric payloads, retained top-one semantics, 415 original keys and SaveReader v10.
- An **opt-in private original-file test** is supplied in `PostV14PrivateFiveSaveAcceptanceTests.cs`. Set `RWS_PRIVATE_POST14_A` through `RWS_PRIVATE_POST14_E` to absolute local paths in a trusted environment; it reads originals only and checks checkpoint lineage, five saved family splits, colony deduplication, re-read idempotence, original SHA/mtime/length. It is **skipped in public CI** and has **not been executed with these five private originals** in this authoring environment. No path, original byte, name, seed, full MOD list or hash is printed or committed.

## Follow-up implementation and verified evidence (same draft PR)

- **P2-A, CPU optimization:** `MetricCalculator.Combine` now builds each colony's by-Def lookup once and caches the missing-key consistency decision; it keeps first-entry behavior and Unknown versus proven-zero semantics. `ImportEngine.Run` now uses a revision-validated per-scan set of successfully read file identities instead of scanning every saved observation for every unchanged file. `ProfileSession.ReadWithRevision` ensures concurrent mutation invalidates the lookup under the lock; tests cover changed reader versions and removal of stored observations during a warm scan.
- **P2-B, conservative MOD/DLC compatibility:** `NumericValue` carries the saved source's MOD fingerprint in-memory. The import reader now copies the verified SaveFile fingerprint to its checkpoint observation. A `cross.top.*` cohort with different or missing saved MOD fingerprints is marked **Partial**, not silently marked Complete. Measured sums are shown as partial evidence, not claimed as compatible or verified data. DLC-disabled zero versus DLC-enabled observed zero versus DLC-enabled missing entry are covered by synthetic 3-colony tests; saved hash/DLC profile JSON round-trip is verified.
- **Private real-file structural checks (not production .NET):** all five new originals independently parsed read-only using Python/lxml. Exactly 25/25 scalar-to-by-Def comparisons reconciled (sown, sold units, bought units, crafted, mined), all five 123-key/123-value research dictionaries paired, exactly one confirmed direct parent among the five. Bytes/SHA-256, length and mtime were unchanged; neither IDs nor hashes were published. Three older originals were separately checked; all eight have one matching MOD inventory and only three confirmed direct edges across eight, **not** eight independent colonies. ### Non-negotiable remaining gates

Historical `researchManager/progress` only stores progress, not a proven `ResearchProjectDef.IsFinished` result. A positive progress value cannot be promoted to a finished project without version- and MOD-matched game Def/cost/techprint proof. Map `Pawn` elements do not prove free-colonist ownership, world/caravan inclusion or non-slave status; raw Things cannot prove eligible stock/inventories or minified/holder deduplication; serialized generator presence cannot prove positive `CompPowerPlant.PowerOutput`. Medical event histories cannot be reconstructed from a saved hediff set. These P0-C/P1-A–D **remain unimplemented** as historical backfill; writing arbitrary counts would violate the research plan and corrupt the global totals.

**Remaining gates after genuine private .NET acceptance:** The 49 *R2 legacy* originals were **successfully read with this production reader commit** in [RWMT run #42830780995](2026-11-10-private-r2-49-original-net-acceptance.md): 49/49 original copies unchanged, 0 errors, 12-build distribution matches, p50 36.808 ms / p95 125.850 ms / median allocation 808,696 bytes. This is a **single real batch** and no matched v1.4 baseline or gameplay TPS. Owner-only production .NET read of the *five distinct 1.7.5000* private originals (not R2), 55+ independent real files, five matched RimWorld TPS windows, ten paired saves, and the full cross-MOD game matrix remain unavailable/unrun. The preexisting RWMT qualified 1.7.4985 smoke targets a different older Statistics SHA and cannot be substituted for this feature's gameplay acceptance. Do not claim R07–R11/R13–R14 are fully passed.
