# 対応MOD一覧 / Supported gameplay mods

**対象 / Reference release:** [Rimworld Statistics v1.7.0](https://github.com/pengin0503/Rimworld-Statistics/releases/tag/v1.7.0) · RimWorld 1.7 · 2026-11-14 時点

この一覧は **Rimworld Statistics本体にMOD固有の統計取得コードが含まれる、外部ゲームプレイMOD** を示します。各MODの全機能への対応や、すべての組み合わせでの動作保証を意味しません。汎用の採掘・戦闘・取引などで集計できるだけのMODは含めていません。作者自身のゲームプレイMODも一覧から除外しています。

This page lists external gameplay mods for which **Rimworld Statistics includes dedicated statistics collection code**. It does not imply coverage of every feature or guaranteed compatibility with every mod version or load order. Mods covered only by generic statistics, and the author's own gameplay mods, are excluded.

**内訳 / Catalog:** 通常の実装対象 **37件** + 対象MODの1.7動作条件に留保がある実装 **3件** = **40件**。追加機能を含む未マージPRや、実装予定の候補は含めません。 / **37 regular integrations + 3 conditional integrations = 40**; unmerged PRs and research-only candidates are excluded.

## 記録条件と制限 / Recording conditions and limitations

- **別アドオン不要 / No separate statistics add-on.** 対応コードはRimworld Statistics本体に統合されています。各ゲームプレイMODは、その統計を取得するときだけ必要です。 / Collection is built into Rimworld Statistics; install each gameplay mod only when its metrics are needed.
- **初期設定で有効 / Enabled by default.** 新規設定では利用可能な統計を表示・取得対象とします。既存ユーザーが明示的にOFFにした選択は維持します。 / New installs enable available acquisition by default; explicit existing opt-outs are respected.
- **記録開始以降 / No invented history.** イベントの累計は取得有効化後に観測した分のみです。MOD導入前の履歴をセーブから復元できるとは限りません。対象MODを外しても記録済みの値は保持します。 / Event totals begin when recording is enabled; historic events cannot always be reconstructed, and already recorded values are retained.
- **スナップショット / Snapshots.** 車両・前哨基地・貯水などの「保存時点」の項目は、累計生産・累計建造回数ではありません。 / Save-state metrics must not be interpreted as lifetime production or construction totals.
- **任意の前提条件 / Optional prerequisites.** 一部の統計は対象MODのほかにDLCやフレームワークを必要とします。利用できないものは取得を行いません。 / Some metrics require optional DLC or frameworks; unavailable integrations are skipped.
- **検証状態 / Validation.** コードの存在とRimWorld 1.7での実ゲーム検証完了は別です。未検証の内部API、MOD更新、ロード順によって取得できない場合があります。 / Code inclusion is not proof of in-game validation across all upstream versions and load orders.
