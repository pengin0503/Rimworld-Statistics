## 3. Exact retrieval and verification recipe

Access **through connected Cloudflare**, using read-only REST operations. Never copy object bodies to the public GitHub repository or attach them to issues:

1. Enumerate buckets with `GET /accounts/{account_id}/r2/buckets`; require the explicitly named `rimworld-17`.
2. Enumerate `GET /accounts/{account_id}/r2/buckets/rimworld-17/objects?prefix=...&per_page=1000`. Continue with `cursor` while `result_info.is_truncated` is true. `delimiter=/` is for directory discovery only and does not provide a complete object inventory.
3. Read `Game-Linux/Version.txt` **before** relying on any `research/vanilla-1.7.4985-audited/` metadata. Reject a mismatched exact game version; do not accept a matching `major.minor` alone.
4. Read `START-HERE.md`, `index.json`, `audit-summary.json`, `resumption/continuation-summary.json`. The audited bucket includes `tools/status_source.js` (source metadata size/ETag validation, not full SHA) and `tools/query_r2.js` (type/method/Def lookup), plus decompressed evidence references; document and check the result's `valueState`.
5. Recheck Def and runtime candidates against exact `Game-Linux/Data/...xml`, audited `resolved/all-five.json.gz` and `assembly/Assembly-CSharp/`. Static values omit constructor defaults, generated Defs and other mod patches.
6. For original-save acceptance, **stream in a private runner** under a read-only R2 token/role or the existing `RimWorld-for-mod-test` qualified workflow. Inspect one original at a time, verify pre/post SHA/size/mtime in the private runner and emit only *anonymous counts/acceptance status*. `Saves/` is **not** an authorized set of public fixtures.
7. A new build from the user's 1.7.5000 checkpoint requires its own corresponding game DLL/Def corpus before auto-completing research or stock. Put it under a **separate versioned prefix**, preserve the 4985 corpus and update the source manifest before changing the reader.

## 4. Decisions already resolved (do not reopen without contradictory evidence)

- **Keep** existing 415 registered definitions (331 + 84 derived); no new single-save current/latest-only stats.
- **Keep** `SaveReader.Version == 10` and original checkpoint v1 until a genuine stored reader enhancement is added.
- **Keep** version-specific research/roster/stock/facilities backfill **Unknown or Partial** if required exact Def/Comp state cannot be demonstrated. A saved positive research progress, raw Pawn node, raw Thing count or building Def alone is insufficient for a complete value. This is a data-integrity rule, not a request to repeat research.
- **Keep** original old plans while referenced by live design and tests. Mark them historical/superseded via a compact **[documentation status index](../superpowers/README-current-and-historical.md)**; remove a file only if no live reference needs it and the replacement retains its evidence. Unreviewed mass deletion creates new research work.
- **Treat R2 material as private** even though listing is available via the connected Cloudflare account. Only capture keys for versioned public game reference corpora and source-manifest/document schema; never publish `Saves/` object names, IDs, full contents or per-save hashes.
