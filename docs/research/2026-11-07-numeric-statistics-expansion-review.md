# 数値統計拡張の設計レビュー

[確定設計](../superpowers/specs/2026-11-07-numeric-statistics-expansion-design.md) · [候補台帳](../superpowers/specs/2026-11-07-numeric-statistics-expansion-metrics.md) · [取得根拠](2026-11-07-numeric-statistics-expansion-evidence.md) · [実装計画](../superpowers/plans/2026-11-07-numeric-statistics-expansion.md)

## 1回目 · 候補とゲームデータの照合

| 指摘 | 設計への反映 |
|---|---|
| 統合グループ名だけでは出力や表示が決まらない | 323行にID・元候補・一次分類/統合先・優先・キー・定義を付け、取得根拠と作業単位へリンク |
| 敵無力化/ダウン、個人死亡時最高齢、調理、研究期間の最大、難易度別クリア、DLC出生が重なる | 7つの別名を正規IDへ統合。プレイヤー側か敵対側か、死亡かダウンかは独立した集計条件 |
| 履歴の名目日と真の発生時刻を混同 | 30000 tickの観測日と明記、開始整合の条件と旧版ゲートを定義。無ホーム時の直前値複製と心情0の曖昧性を記録 |
| クエストが保存されることを生涯累計と解釈していた | 保持された受諾・成功・失敗・期限切れに限定。削除経路、未知状態、重複ID、終了処理の時刻差を考慮 |
| 研究/在庫/設備のXMLを少し見れば旧セーブ全体の状態を復元できるという前提 | 保存時にゲームの完了述語・Thing分類・ホーム判定を使う。旧版に必要なデータがなければ未記録 |
| 前後の総資産差から襲撃の直接損失を導けない | R-011を見送り。該当IDと根拠のみ保存 |
| 署名一致とランタイム動作の区別が必要 | 1.7.4985/4995/5000のRimRefで36メソッド名を照合し、実体の発火試験と区別 |

## 2回目 · 互換性、永続化、負荷

| 指摘 | 設計への反映 |
|---|---|
| v1観測の枝刈りに拡張値を足すと値が消え、単に無効化すると既存コロニーの見え方が変わる | 別の要約コレクションを採用。v1で確定したコロニーへ後から帰属 |
| スキーマ未記載の旧データを現行スキーマと読む実装 | 明示的に1へ固定。初回変更時にv1を別名保護、未来版の読取専用と外部変更検知を継承 |
| セーブ成功とファイル存在は同義でなく、後処理で失敗することがある | Prefix→書込確認→正常Postfix→Finalizerの責務を定義。最終rwsの再読で回収する経路を追加 |
| 同じコロニーのコピー・別経路・並行子を加えると二重計上 | ハッシュ/チェックポイントで一意化。代表枝1本、同tickの安定タイブレーク、確証のない系譜は不明 |
| 商談のPostfixでは明細がResetされ、死亡前処理だけでは確定死にならない。通常研究ではFinishProject呼出し前に完了値へ達する | 成立前後をスコープ化。死亡遷移と研究進捗の変更前後を観測 |
| C/Dの全候補に監視を入れると負荷と互換性の面でリスクが高い | 検証済み出力だけ独立登録。1ファミリーのキー上限、1回の保存走査、画面の非同期準備、数値目標を設定 |
| v1 `GetView` をUIから直接呼ぶと重い | 既存バックグラウンド更新を流用し、描画はキャッシュ済みDTOのみ |

## 3回目 · 実装者視点の独立レビュー

独立レビューは1名。実装判断が必要な箇所を確認し、以下を修正した。

| 指摘 | 修正と回帰条件 |
|---|---|
| 置換後に後処理が失敗したFを回収すると、その後同じ親Pから保存したSと枝になる | 保存系譜の分岐と明確化し、巻き戻し操作の検出とは区別。P→失敗F→ロードなしS、P→失敗F→Fロード→Tの2ケースを追加。ロード時の同ロック回収を明記 |
| 心情先頭0は不明なのに継続期間のテストが数値を期待していた | 開始整合した `[60,0,40,85]` の部分観測と `[0,40,85]` の開始不明を分け、期待値を修正 |
| 現在のDLCゲートで過去の有効記録が消える可能性 | 出荷済みの解釈/表示Registryと現在の取得ゲートを分離。DLC無効時の履歴表示、旧DLC無し/不明のfixtureを追加 |
| 後続する他MODのPostfix失敗を本MODの成功判定で予見できない | 成功境界はSafeSaver本体と本MODの確認まで。後続パッチだけの例外では確定済み記録を維持するfixtureを追加 |

## 引き継ぐ検証

| 検証 | 現時点 | 未成立の場合 |
|---|---|---|
| 実1.5/1.6/1.7 XMLの拡張系列・クエスト | 旧49件の調査記録あり。今回の元データ再照合なし | 版ごとに確認済み出力だけを有効化。特に旧版の日時・継続時間は閉じる |
| 1.7.4995/5000の実体・Harmony | 36メソッド名の参照署名一致。ゲーム実体の実行は未確認 | 該当アダプターを無効。v1/A、他ファミリーは使用可 |
| DLCと競合MOD（RimSaves、Combat Extended、独自収納等） | 静的な境界と陽性/陰性条件を記録。AnomalyのローカルDefなし | 対応を確認できた部分のみ表示、DLC/機能単位で無効化 |
| 性能 | 基準と測定シナリオを定義。実装後の計測値なし | 閾値未達の取得単位をリリース対象から外す |

これらは実装後の動作確認または対応環境のゲート。未確認な対象に対する既定動作は設計済み。特定のゲートを通過できないことを、別の資料調査や仮のイベント実装で埋めない。
