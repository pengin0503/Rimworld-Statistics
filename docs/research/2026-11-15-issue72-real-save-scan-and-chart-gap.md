## 2. 実セーブ55件の走査（v1.2.2 との比較）

- 55ファイル（`.rws` 52件、`.rws.old` 3件）、合計 902MB（中央値 16.3MB、最大 32.2MB）。1.5 が22件、1.6 が20件、1.7 が13件。チェックポイントを持つのは 1.7.5005 の6件だけ。
- 基準：v1.2.2（Issue 作成時の正式版、過去セーブ復元の前）。同じ計測コード（公開APIのみ）を両方の Core でビルドし、交互に3回実行した。1回の実行では、新しい空のプロフィールへの取込（初回）と、続けての再走査（全件スキップ）を3回繰り返す。OSのファイルキャッシュは消せないため、「初回」は空のプロフィールへの取込を指す。
- 1回目はプロセス起動直後（JITを含む。ゲーム起動後の最初の取込に相当）、2〜3回目は同じプロセス内での繰り返し。

| 項目（3回の範囲） | v1.2.2 | main |
|---|---:|---:|
| 初回取込：1回目 時間 | 4.65〜5.52秒 | 3.40〜3.48秒 |
| 初回取込：1回目 CPU | 7.1〜8.2秒 | 8.2〜8.4秒 |
| 初回取込：2〜3回目 時間 | 2.19〜2.39秒 | 1.24〜1.40秒 |
| 初回取込：2〜3回目 CPU | 3.7〜4.6秒 | 3.8〜4.3秒 |
| 初回取込の割当 | 86〜96MB | 57〜61MB |
| 再走査（全件スキップ） | 10〜39ms | 11〜34ms |
| 再走査の割当 | 5.1〜6.1MB | 1.9MB |
| 最大ワーキングセット | 115〜190MB | 136〜160MB |
| 保存観測 / プロフィール | 55件 / 524KB | 55件 / 663KB |
| 読込失敗 / 元ファイルの変化 | 0 / なし | 0 / なし |

main は v1.2.2 より多くを読む（チェックポイント、派閥・施設の部分復元、MOD統計など）。それでも、先読みの並列化により時間は短い。CPU時間は同程度で、割当は少ない。

main で取り込んだ内容：チェックポイント5件、証明できた区間2本（増分はいずれも0）、派閥の部分復元12件、本拠地の部分復元13件。保存観測55件に対し、セーブファイルの統計行は51件だった。残る4件（1.5/1.6、うち2件は `.rws.old`）は、同じ指紋・同じMOD構成で、より後のtickを持つ同じコロニーのセーブへ、既存の規則で統合されたものである（`ProfileMutations.Supersedes`）。保存観測は4件とも残っている。

合成3,000件のプロフィール計測（`ProfileBenchmark` 既定、2回）：プロフィールは 212KB から 287KB に増え（保持行 36→48）、追加・直列化・表示構築は誤差の範囲で同程度だった。ディスクへの書込は 12〜17ms から 1.1〜1.7ms に短縮された（#195）。

再現：`tools/SaveImportBenchmark -- --dir <フォルダ> 3`（今回追加、[手順](../testing/2026-11-09-private-historical-backfill.md#real-save-folder-benchmark-2026-11-15)）。内容の正しさは、既存の任意実行テスト `PrivateHistoricalBackfillAcceptanceTests`（`RWS_PRIVATE_SAVES_DIR`）で確認した。55件すべて読込・再走査55件スキップ・Partial の確認・元ファイル不変、初回 2,994ms、再走査 90ms。

## 3. チェックポイントのグラフ：系統の途切れより前の記録

親の欠落（その親を含むセーブを取り込んでいない）で系統が途切れると、それより前の記録がグラフから消えていた（6件では19:33の点）。途切れより前のチェックポイントを残し、証明できる親子の間だけを結び、途切れの直後の点を白抜きにするよう変更した。規則・性能・テストは[設計 §8](../superpowers/specs/2026-11-14-chart-history-lineage-design.md#8-追補2026-11-15チェックポイントのグラフで系統の途切れより前の記録を残すissue-72)に記載した。

## 4. 残る実証

- **正の差分の実例**：襲撃または入植者の死亡が増えた、直接の親子関係にある2つのセーブ。この版では、統計に変化がなくても保存ごとに新しいチェックポイントを確定する（PR #267）ので、今後のセーブは親子をたどりやすい。
- **ゲーム画面での確認**：取込画面の区間表示、グラフの白抜き・線・ツールチップ。
- **所有者のPCでの計測**：上の `--dir` を同じフォルダで、この版と比較したい版の両方で実行する。TPS とセーブ時間は、ゲーム内で別に測る必要がある。
