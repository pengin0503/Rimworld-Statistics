# v2.0.0候補の既存RimWorld MODとの重複・独自性調査

- 調査日：2026-11-17
- 対象：`pengin0503/Rimworld-Statistics`（調査時main `714281230834f822b7f8b6a1154de79a50b7c504`）
- 目的：既存MODの機能と競合する範囲を明示し、v2.0.0候補の実装可否と差別化条件を決める。
- 状態：**調査と候補整理のみ。コード・MOD・Release・Workshopは更新しない。**
- [v2.0.0実装前設計](../superpowers/specs/2026-11-17-v2-0-distinctive-features-design.md)

## 結論

**類似機能があることと、他MODのコード・表現を模倣することは別。** 年表、ダッシュボード、グラフ、実績表示はRimWorldの既存MODですでに提供されているため、一般的な機能としての「初実装」「唯一」は主張しない。既存MODのソース、画像、デザイン、文章、独自のデータ構造を流用せず、Rimworld Statisticsの既存データモデルから独立設計・実装する。

全候補を無条件に新規採用するのではなく、**全セーブ横断・コロニー間比較・セーブ分岐の証拠・記録状態**に軸足を移す。存在が確認できる他MODと異なる体験を提供しつつ、統計MODの目的から外れないようにする。法的な完全無リスク保証や、全Workshop作品を調べ尽くしたという主張ではない。

## 候補ごとの判断

| 提案 | 判断 | 差別化の条件 |
| --- | --- | --- |
| **A：コロニー年表** | **条件付き採用（設計を変更）** | 日記や個人のイベントログではなく、**複数セーブに保存された確定記録**と**統計変化の根拠**を年代順に参照する「コロニー記録年表」。時刻不明の事象は時刻不明として示す。推測で復元しない |
| **B：セーブ系統・分岐の可視化** | **採用・優先** | ワールド別フォルダー管理とは異なり、既存の**チェックポイント親子証拠**に基づく読み取り専用グラフ。枝同士の差や欠測を表示。セーブの編集・削除・統合をしない |
| **C：コロニー総括レポート** | **採用・優先** | 現在のコロニー情報カードと違い、**過去を含む複数コロニーの長期記録・順位・情報の取得品質・出典**を一枚に集約。必要なら静的HTMLで書き出す |
| **D：散布図・相関分析** | **採用・中位** | コロニー単位の2指標比較。記録範囲が異なる値を無条件に相関計算せず、欠測・集計方式・期間の違いを表示。統計の一般的表現であって独占性は主張しない |
| **E：通算マイルストーン・自己記録** | **「実績システム」は不採用、自己ベスト履歴に限定して条件付き採用** | 解除条件・達成報酬・ポップアップ・ポイントは実装しない。**全コロニーの記録更新・過去最高値の確認**に特化し、既存ランキングとの差分を証明できる場合のみ実装 |

## 本MODがすでに実装済みの機能（重複禁止）

- タイトル画面からの全セーブ／全コロニー統計、コロニー比較、ランキング、お気に入り、CSV出力、バックアップ・復元、棒グラフと履歴折れ線グラフ、対応MOD統計。
- 履歴グラフの親子証拠・欠測の考え方、保存時スナップショット、日あたり値、区間診断。
- [Issue #307](https://github.com/pengin0503/Rimworld-Statistics/issues/307) では履歴区間の増減・変化率・期間比較を作業対象としている。これを新機能として二重に作らず、完成したAPIをB/C/Dから利用する。

## 独立実装の条件

1. **既存MODのコード・UI画像・文章・アイコン構成をコピーしない。** 類似機能の仕様は参考情報に留め、コア演算・データ保存・UIを自MOD向けに設計する。
2. 保存されていないイベント時刻、未証明のセーブの親子関係、別枝の累計、未観測値を推測で確定させない。
3. 日記、手紙全文、会話ログ、ポーン別人生録の全量記録、報酬付き実績、セーブ管理UIは本件の対象外。
4. 既存のバニラHistoryタブを置き換えない。Rimworld Statistics側の閲覧画面から開く。相互導入で同一画面の置換競合を起こさない。
5. 保存と描画の負荷・ディスク使用量を計測し、セーブの読み取り専用性を維持する。外部SDK・MOD/DLC未導入でも壊れない。
6. 技術的・法的に完全な「類似なし」を保証するものではない。公開時は「初」「唯一」「他MODにない」といった未検証の宣伝をしない。
